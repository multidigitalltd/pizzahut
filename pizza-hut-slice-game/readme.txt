משחק קמפיין ממותג של פיצה האט – "תפוס את המשולש". דף נחיתה עם שורטקוד, טופס לידים, טבלת מובילים ציבורית ואיסוף נתונים בטבלת DB ייעודית.

== Description ==

פלאגין וורדפרס לקמפיין ממותג של פיצה האט. המשתמשים מגיעים מבאנרים לדף נחיתה ייעודי ומשחקים "תפוס את המשולש".

= זרימת המשחק =
1. אינטרו ממותג: לוגו, מקרא פריטים, כפתור "מתחילים".
2. טופס משתתף: שם מלא, טלפון, אימייל, אישור תקנון.
3. ספירה לאחור 3-2-1 ואז 5 שלבים מבוססי-תפיסות:
   שלב 1: 7 תפיסות ב-60 שנ' · שלב 2: 9 ב-45 · שלב 3: 12 ב-35 · שלב 4: 15 ב-30 · שלב 5: 18 ב-25.
4. ניקוד לתפיסה: בסיס (רגיל 1 / זהב 3) × פרנזי ×2 + בונוס מהירות (+1 מתחת ל-1.2 שנ') + בונוס שלב (+מספר השלב−1) + רצף 5 = +2. השלמת שלב = בונוס שלב×3.
5. מכשולים: פטרייה/זית/בצל/עגבנייה −1 · משולש שרוף −2 · שעון +5 שנ' · גבינה +2 · פלפל פרנזי ×2.
6. סוף המשחק: ניצחון (סיום שלב 5) · הזמן של השלב נגמר · 5 פגיעות במכשולים באותו שלב.
7. מסך סיום: מדליית דירוג, ניקוד, תגובה ממוצעת, הרצף הכי ארוך, קונפטי, קופון.
8. טבלת שיאים ציבורית לפי שחקן – ניקוד גבוה = מקום ראשון, ללא טלפון/אימייל.

= כללי דירוג =
* ניקוד גבוה מנצח.
* בשוויון – זמן תגובה ממוצע קצר יותר מנצח.
* בשוויון נוסף – ההגשה המוקדמת מנצחת.

= טכני =
* מבנה פלאגין וורדפרס נקי ומודולרי.
* טבלת DB ייעודית לניקוד ולידים.
* AJAX עם אימות nonce.
* סניטציה מלאה של כל הקלטים.
* שמירת ניקוד, משך, זמן תגובה ממוצע, פרטי משתתף, שדות UTM, hash של IP ושל User Agent.
* טעינת נכסים רק כאשר השורטקוד נוכח בעמוד.
* רספונסיבי מלא למובייל ולדסקטופ.
* אנטי-רמייה: טוקן חד-פעמי לכל משחק, הגבלת קצב לפי IP, חסמי ניקוד/לחיצות/משך/זמן תגובה.
* גופני מותג מקומיים: אלמוני – כותרות בבולד וטקסט רץ (מכמורת ארוז לשימוש עתידי) – ללא תלות ב-Google Fonts.

== Installation ==

1. העלו את תיקיית `pizza-hut-slice-game` לתיקיית `/wp-content/plugins/`.
2. הפעילו את הפלאגין דרך תפריט "תוספים" בוורדפרס (בהפעלה נוצרת טבלת ה-DB).
3. הוסיפו לעמוד הנחיתה את השורטקוד `[pizza_hut_slice_game]`.
4. צפו בתוצאות ובלידים תחת תפריט "משחק פיצה האט" בגב האתר, כולל ייצוא CSV.

== Shortcode ==

`[pizza_hut_slice_game]`

פרמטרים אופציונליים:
* `title` – טקסט הגלולה שליד הלוגו (ברירת מחדל: "תפוס ת'משולש").
* `logo` – URL ללוגו. ריק = הלוגו הרשמי המצורף לתוסף.

שורטקוד נוסף: `[pizza_slice_leaderboard limit="8"]` – טבלת השיאים בלבד, בעיצוב מסך הסיום.

== Landing Page Template ==

התוסף מוסיף לעורך העמודים תבנית עמוד בשם "Pizza Hut – דף נחיתה מלא":
עמוד נקי במסך מלא, ללא ה-header/footer של התבנית הפעילה – אידיאלי לנחיתה מבאנרים.
בחרו את התבנית בהגדרות העמוד (Template) והוסיפו את השורטקוד לתוכן העמוד.

== Privacy ==

הפלאגין אוסף פרטי משתתף (שם, טלפון, אימייל) בהסכמה מפורשת (checkbox חובה).
כתובת ה-IP ומחרוזת ה-User Agent נשמרות כ-hash חד-כיווני בלבד (SHA-256 עם מלח).
טבלת המובילים הציבורית אינה חושפת טלפון או אימייל – רק שם תצוגה מקוצר.
